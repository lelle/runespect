The in-page overlay shows values one component at a time: a click on a component's name, or on (+) and (−), opens and closes its values in place, and all start closed, so a large page's tree stays readable. Open in editor is a </> beside the name, as in the panel. ⚙ → **Values** → **Beside the tree** shows names only, with the selected component's values below a divider you can drag. Selecting, picking or searching to a component opens it. The heading and filter stay put while the tree scrolls, scrolling over the overlay no longer scrolls the page behind it, and the ⚙ menu shows whole over a short overlay. A names-only tree, in the overlay or the panel, says on a line below it which keys move in it. The detail pane follows ⚙ → **Flash on update**, in the panel too.
