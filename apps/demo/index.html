Try this
  • Add to cart: a CartLine joins the tree; remove it and it leaves.
  • Tick Only components with state under ⚙ in the panel: Footer, which has no values, goes.
  • Pick Quantity and change value, a $bindable prop.
  • Pick Cart and type SPRING as coupon.
  • Check out: Checkout mounts, and the order lands in orders.svelte.ts.
